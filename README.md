# 漫画书架 · Manhua Reader

 > 当前版本 **v0.4.0**（更新记录见 [CHANGELOG.md](CHANGELOG.md)）

一个本地优先的桌面漫画阅读 APP（Electron + 原生前端，无 Web 服务依赖）。
支持把 **本地文件夹**、**本地压缩包 (zip/cbz)**、**WebDAV 网络存储** 里的漫画加入书架，
并以「一张长图」的方式连续向下滚动阅读。

---

## 功能

| 需求 | 实现 |
| --- | --- |
| 添加本地漫画资源 | 选择文件夹（自动递归子目录，按文件名自然排序）；支持一次选择多个 |
| 添加压缩包漫画 | 读取 zip/cbz 内的图片，随机访问、不整包解压到内存 |
| 添加网络存储 | 标准 WebDAV（坚果云 / Nextcloud / 群晖等），支持无认证、Basic、Bearer |
| 浏览书架 | 封面网格、搜索、阅读进度条、页数角标 |
| 手工设置名字与头图 | 编辑弹窗：改名 / 从漫画页中选封面 / 从本地文件选封面 / 恢复默认 |
| 长图式连续阅读 | 所有页按同一宽度无缝拼接成一条长卷，滚动即加载 |
| 缩放 | 以 **APP 窗口宽度** 为基准的百分比缩放（不是按图片像素），100% = 铺满窗口宽度 |
| 记忆进度 | 自动记录读到第几页、页内偏移；再次打开自动回到原处 |
| 按页跳转 | 底部滑块 + 页码输入框 + 上一页/下一页按钮 |

## 运行

```bash
npm install
npm start          # 启动 APP
npm run dev        # 启动并输出渲染进程日志
```

## 打包

```bash
npm run dist       # 生成 release/ 下的 dmg / zip
npm run dist:dir   # 只生成 .app 目录
```

产物：`release/漫画书架-0.2.0-arm64.dmg`（macOS）、`release/漫画书架-0.2.0-arm64-mac.zip`。
未做代码签名，首次打开需在「系统设置 → 隐私与安全性」中允许。

> 打包完成后会自动删除 `release/mac-arm64` 里的「未打包 .app 中间产物」
> （`scripts/after-build.js`）。因为项目目录在 `~/Documents` 下会被 Spotlight 索引，
> 留着它会让 Cmd+Space 搜出两个「漫画书架」。安装只需用 dmg 拖一次到「应用程序」。

## 阅读方向

工具栏右上角有三个方向按钮（↓ ← →），可随时切换，切换后会记住该漫画的方向：

图标 = **翻页推进的方向**（与 ↓ 向下阅读的语义保持一致）：

| 方向 | 布局 | 第 1 页位置 | 翻页方向 | 适合 |
| --- | --- | --- | --- | --- |
| **↓ 向下阅读** | 竖排长图，页面上下无缝拼接 | 最上方 | 向下 | 条漫 / 竖版漫画 / 网页长图 |
| **← 向左阅读** | 横排，页面左右排成一条 | **最右侧** | 向左 | 日漫（从右往左读，右起） |
| **→ 向右阅读** | 横排，页面左右排成一条 | **最左侧** | 向右 | 欧美漫画（从左往右读） |

- 方向也可以在「编辑漫画信息」里设为该漫画的默认方向
- 横排时缩放基准变为**窗口高度**（100% = 页面高度刚好铺满窗口），超宽的跨页会自动改为按宽度适配
- 横排模式下鼠标滚轮会自动变成横向滚动
- 键盘方向键跟随阅读方向：`→` 模式下右键=下一页，`←` 模式下右键=上一页；空格永远是下一页
- 切换方向时保持当前页不丢，阅读进度照常记忆

## 快捷键（阅读中）

| 按键 | 作用 |
| --- | --- |
| `←` / `→` / `↑` / `↓` / `空格` | 上一页 / 下一页 |
| `+` / `-` | 放大 / 缩小（相对窗口宽度） |
| `0` 或 `F` | 复位为 100%（适应窗口宽度） |
| `H` | 进入 / 退出沉浸模式 |
| `Esc` | 返回书架 |

**沉浸模式**：进入后工具栏自动隐藏；把鼠标移到屏幕**顶部**（或**向上滚动**）工具栏会重新出现，
屏幕顶部会出现「⤢ 退出沉浸模式」的提示条，点它或按 `H` 即可退出。
顶部工具栏上的 **◐ / ◑** 按钮可切换浅色 / 深色阅读背景。

鼠标滚轮即滚动长图；底部滑块可快速在整本之间定位。

## 扫描性能（大目录 / NAS）

添加漫画时的目录扫描做了针对性优化（网络盘尤其明显）：

- **并发遍历**目录树（本地 32 路 / 网络盘 12 路），不再一个目录一个目录串行等
- **去掉每个文件的单独 stat**，文件大小在扫描时不再逐个询问
- **不再逐页读取图片头**：只探测前 24–60 页的真实尺寸，其余按中位数比例估算，
  阅读时图片加载会自动校正比例（不会影响排版准确性）
- **扫描过程有实时反馈**：弹窗显示已发现多少张图片、已扫描多少目录、已用时多久，
  可点「放到后台继续」——扫描在后台跑，APP 依然可用，完成后提示

实测（你的 NAS：`/Volumes/NANas._smb._tcp.local/pic/非常運動`，2439 张）：

| 策略 | 耗时 |
| --- | --- |
| 旧（串行遍历 + 每文件 stat + 逐页探测尺寸） | **70.0 秒** |
| 新（并发遍历 + 少量探测） | **0.27 秒** |

> 对网络挂载点（`/Volumes/...`）会自动降低并发和探测数量，避免打爆网络。
> 大画集（>800 页）会按比例自动降低进度写盘频率，避免频繁重写元数据。

## 电子书支持（PDF / EPUB / MOBI / AZW3）

「＋ 添加漫画 → 📕 电子书」可以添加电子书，和漫画共用同一套阅读器：

| 格式 | 解析方式 | 说明 |
| --- | --- | --- |
| **PDF** | pdf.js（pdfjs-dist，Apache-2.0） | 逐页渲染到画布，矢量文字清晰可放大 |
| **EPUB** | foliate-js（MIT） | 按 spine 顺序分章，保留书籍自带 CSS 与目录 |
| **MOBI / AZW3** | foliate-js（MIT） | 支持 PalmDOC / HUFF-Cdic 压缩与 KF8 结构 |

- 电子书的「页」= PDF 页 或 书籍章节，长卷阅读、滚动加载、缩放、进度记忆、跳页全部照常
- 打开时自动读取书籍元数据（书名/作者）填入条目名，书架上显示「N 页」或「N 章」
- EPUB / MOBI 有目录时，工具栏会出现 **☰ 目录** 按钮，可直接跳章
- 电子书也支持三种阅读方向与沉浸模式；文字类建议用「↓ 向下阅读」
- 缩放对文字书是缩放字号，对 PDF 是提高渲染分辨率

> 依赖与许可：`pdfjs-dist`（Apache-2.0）、`foliate-js`（MIT，见 `src/vendor/foliate/LICENSE`）

**实测结果**（用 `~/Movies/0Books` 里的 16 个真实文档批量验证，全部通过、图片零破损）：

| 格式 | 样本 | 结果 |
| --- | --- | --- |
| PDF | 10 个（3–782 页，含 245MB 的《中国淡水鱼类图鉴》） | 全部解析渲染正常，245MB 的书打开仅 288ms |
| EPUB | 4 个（29–72 章） | 章节、目录、插图全部正常 |
| MOBI | 4 个（183–1362 节，含《进击的巨人》漫画 MOBI） | 图片资源正常内联，漫画页自动铺满宽度 |

## 书架整理

- **拖拽排序**：按住书卡或文件夹拖动即可排序；拖到另一张书的前/后插入，拖到文件夹上归类，拖到空白处移回根目录
- **收藏夹**：右上角「📁 新建文件夹」自建分类；书可拖进文件夹，或用卡片菜单「📁 移动到文件夹」；文件夹支持重命名、删除（书回到根目录）、折叠
- **电子书合集**：「📚 电子书合集（选文件夹，多卷合一）」把一个目录里的多卷合成一本（如《进击的巨人 1-19卷》），「🧩 电子书合集（多选文件合一）」同理；各卷按文件名自然排序接续，目录里每卷一个条目可直达

## 存储与缓存（重要）

**APP 不会复制、缓存或改写你的漫画文件**，所有图片都是按需从原位置读取：

| 资源类型 | 读取方式 | 是否占用额外硬盘 |
| --- | --- | --- |
| 本地文件夹 | 每次打开直接流式读原文件 | 否 |
| 本地压缩包 | 随机解压单个条目到内存 | 否 |
| WebDAV | 首次下载后放进**内存**缓存（上限 256 MB），避免来回滚动重复下载 | 否（内存，非磁盘） |

- 漫画资源响应统一带 `Cache-Control: no-store`，浏览器**不会**把漫画图片写进磁盘缓存
- APP 磁盘上只保存一份 `library.json` 元数据（路径、尺寸、阅读进度），实测 58 页的漫画约 14 KB
- 实测：完整读完一本 14 页漫画后，APP 数据目录体积从 2908 KB 变为 2912 KB（仅元数据增长），目录内 **0 个图片文件**
- 书架右上角 🧹 按钮可随时清理缓存（释放内存中的网络图片 + 浏览器缓存）

## 数据存放

- 书架数据：`~/Library/Application Support/漫画书架/library.json`（Windows：`%APPDATA%/漫画书架`）
- 可用环境变量 `COMIC_USER_DATA` 指定其它目录（多书库 / 测试用）
- 原始漫画文件不会被修改或复制，APP 只做读取

## 已知限制

- 压缩包仅支持 **zip / cbz**（未加密）；RAR / 7z 需要额外解压工具
- WebDAV 需服务端支持 `PROPFIND`（绝大多数主流网盘支持）
- 图片尺寸探测只读文件头，因此能提前占位、滚动不跳动；个别特殊格式可能按默认比例估算，加载后会自动校正
- **带 DRM 的 MOBI/AZW3 仍无法读取**（加密是内容自带的，程序无法绕过）；检测到后会明确提示「带 DRM 保护，无法读取」
- EPUB 章节里的**内联 CSS 背景图**若与章节不在同一目录，可能显示不出来（章节正文插图、SVG 封面都正常）
