# 漫画书架 · Manhua Reader

> 当前版本 **v0.4.2**（更新记录见 [CHANGELOG.md](CHANGELOG.md)）

一个本地优先的桌面漫画阅读 APP。支持把 **本地文件夹**、**本地压缩包（zip/cbz）**、**WebDAV 网络存储** 里的漫画和电子书加入书架，并以「一张长图」的方式连续向下滚动阅读。

---

## ✨ 特点与优势

| 亮点 | 说明 |
| --- | --- |
| **零服务器、零账号** | 纯本地桌面应用，不上传任何数据、不需要登录 |
| **不复制、不缓存漫画** | 原文件只读打开，磁盘上只多出一份几 KB 的元数据 |
| **长图连续阅读** | 所有页按同一宽度无缝拼成一条长卷，滚动即加载，没有翻页等待 |
| **三种阅读方向** | ↓ 向下 / ← 向左 / → 向右，分别适配竖版条漫、日漫、欧美漫画 |
| **多源接入** | 本地目录、zip/cbz 压缩包、WebDAV 网络盘（坚果云 / Nextcloud / 群晖等） |
| **漫画 + 电子书** | PDF / EPUB / MOBI / AZW3 与漫画共用同一个阅读器 |
| **大目录秒开** | 并发扫描 + 抽样探测尺寸，2439 张的大目录从 70 秒降到 0.27 秒 |
| **进度记忆** | 自动记录读到第几页、页内偏移，下次打开原地续读 |
| **轻量纯净** | Electron + 原生前端，无 Web 服务、无后端依赖 |

### 与常见阅读器的不同

- **不改你的文件**：不少阅读器会把图片复制进自己的缓存库，时间久了占掉几十 GB；这里始终按需从原位置读取。
- **网络盘友好**：对 SMB / WebDAV 挂载点自动降低并发和探测频率，避免打爆网络。
- **多卷合集**：一个目录里的多卷可以合成一本，卷与卷之间连续可跳。
- **不打扰**：没有账号、没有云同步、没有推荐位，打开就是你的书架。

## 🚀 快速开始

1. 启动 APP，点「**＋ 添加漫画**」；
2. 选择来源：
   - **📁 本地文件夹** — 选一个或多个目录，自动递归子目录并按文件名自然排序；
   - **🗜 压缩包** — 选择 zip / cbz 文件，随机读取内部图片，不整包解压到内存；
   - **📕 电子书** — 添加 PDF / EPUB / MOBI / AZW3；
   - **☁️ 网络存储** — 填入 WebDAV 地址（支持无认证 / Basic / Bearer）；
   - **📚 电子书合集** — 选一个含多卷的目录，合并成一本；
3. 在书架上点开任意一本即可开始阅读。

## 📖 阅读操作

### 阅读方向

工具栏右上角有三个方向按钮，可随时切换，切换后会按书记住该书的方向。图标表示 **翻页推进的方向**：

| 方向 | 布局 | 第 1 页位置 | 适合 |
| --- | --- | --- | --- |
| **↓ 向下阅读** | 竖排长图，页面上下无缝拼接 | 最上方 | 条漫 / 竖版漫画 / 网页长图 |
| **← 向左阅读** | 横排，页面左右排成一条 | **最右侧** | 日漫（从右往左读，右起） |
| **→ 向右阅读** | 横排，页面左右排成一条 | **最左侧** | 欧美漫画（从左往右读） |

- 竖排时缩放基准是 **窗口宽度**：100% = 页面正好铺满窗口宽度；横排时缩放基准变为 **窗口高度**（100% = 页面高度刚好铺满窗口），超宽跨页自动改为按宽度适配
- 每次打开漫画都从 100% 开始；窗口跨屏或改变大小后会自动重新铺满，缩放百分比显示始终与实际一致
- 横排模式下鼠标滚轮自动变成横向滚动
- 键盘方向键跟随阅读方向；空格永远是下一页
- 切换方向时保持当前页不丢，阅读进度照常记忆

### 快捷键

| 按键 | 作用 |
| --- | --- |
| `←` / `→` / `↑` / `↓` / `空格` | 上一页 / 下一页 |
| `+` / `-` | 放大 / 缩小（相对窗口宽度） |
| `0` 或 `F` | 复位为 100%（适应窗口宽度） |
| `H` | 进入 / 退出沉浸模式 |
| `Esc` | 返回书架 |

**沉浸模式**：进入后工具栏自动隐藏；把鼠标移到屏幕 **顶部**（或 **向上滚动**）工具栏会重新出现，顶部提示条点一下或按 `H` 即可退出。工具栏上的 **◐ / ◑** 按钮可切换浅色 / 深色阅读背景。

鼠标滚轮即滚动长图；底部滑块可快速在整本之间定位，页码输入框可直接跳页。

## 📚 支持的格式

| 类型 | 格式 | 读取方式 |
| --- | --- | --- |
| 漫画（图片） | 图片文件夹、zip / cbz | 流式读取原文件；压缩包按条目随机解压到内存 |
| 电子书 | PDF | pdf.js 逐页渲染到画布，矢量文字放大后依然清晰 |
| 电子书 | EPUB | foliate-js 按 spine 顺序分章，保留书籍自带样式与目录 |
| 电子书 | MOBI / AZW3 | foliate-js，图片资源自动内联，漫画页铺满宽度 |

- 电子书的「页」= PDF 页 或书籍章节，长卷阅读、缩放、进度记忆、跳页全部照常
- 打开时自动读取书籍元数据（书名 / 作者）填入条目名，书架上显示「N 页」或「N 章」
- EPUB / MOBI 有目录时，工具栏会出现 **☰ 目录** 按钮，可直接跳章
- 电子书也支持三种阅读方向与沉浸模式；文字类建议用「↓ 向下阅读」
- 缩放对文字书是缩放字号，对 PDF 是提高渲染分辨率

> 依赖与许可：`pdfjs-dist`（Apache-2.0）、`foliate-js`（MIT，见 `src/vendor/foliate/LICENSE`）

## 🗂 书架整理

- **拖拽排序**：按住书卡或文件夹拖动即可排序；拖到另一张书的前 / 后插入，拖到文件夹上归类，拖到空白处移回根目录
- **收藏夹**：右上角「📁 新建文件夹」自建分类；书可拖进文件夹，或用卡片菜单「📁 移动到文件夹」；文件夹支持重命名、删除（书回到根目录）、折叠
- **多卷合集**：「📚 电子书合集（选文件夹，多卷合一）」把一个目录里的多卷合成一本，「🧩 电子书合集（多选文件合一）」同理；各卷按文件名自然排序接续，目录里每卷一个条目可直达
- **封面与改名**：卡片菜单「编辑」可改名、从漫画页中选封面、从本地文件选封面，或恢复默认
- **收藏夹也是卡片**：收藏夹是一张带图标和本数角标的卡片，点一下展开 / 收起，里面的书在下方缩进显示

## ⚡ 性能

添加漫画时的目录扫描做了针对性优化（网络盘尤其明显）：

- **并发遍历**目录树（本地 32 路 / 网络盘 12 路），不再一个目录一个目录串行等
- **去掉每个文件的单独 stat**，文件大小在扫描时不再逐个询问
- **不再逐页读取图片头**：只探测前 24–60 页的真实尺寸，其余按中位数比例估算，阅读时自动校正比例（不影响排版准确性）
- **扫描过程有实时反馈**：弹窗显示已发现多少张图片、已扫描多少目录、已用时多久，可点「放到后台继续」—— 扫描在后台跑，APP 依然可用，完成后提示

实测（NAS 上的 2439 张图片大目录）：

| 策略 | 耗时 |
| --- | --- |
| 串行遍历 + 每文件 stat + 逐页探测尺寸 | **70.0 秒** |
| 并发遍历 + 少量探测 | **0.27 秒** |

> 对网络挂载点（`/Volumes/...`）会自动降低并发和探测数量，避免打爆网络。大画集（>800 页）会按比例降低进度写盘频率，避免频繁重写元数据。

## 💾 数据与隐私

**APP 不会复制、缓存或改写你的漫画文件**，所有图片都是按需从原位置读取：

| 资源类型 | 读取方式 | 是否占用额外硬盘 |
| --- | --- | --- |
| 本地文件夹 | 每次打开直接流式读原文件 | 否 |
| 本地压缩包 | 随机解压单个条目到内存 | 否 |
| WebDAV | 首次下载后放进 **内存** 缓存（上限 256 MB），避免来回滚动重复下载 | 否（内存，非磁盘） |

- 漫画资源响应统一带 `Cache-Control: no-store`，浏览器 **不会** 把漫画图片写进磁盘缓存
- APP 磁盘上只保存一份 `library.json` 元数据（路径、尺寸、阅读进度），实测 58 页的漫画约 14 KB
- 读完一本 14 页漫画后，APP 数据目录体积仅增长 4 KB，目录内 **0 个图片文件**
- 书架右上角 🧹 按钮可随时清理缓存（释放内存中的网络图片 + 浏览器缓存）

**数据存放位置**

- 书架数据：`~/Library/Application Support/漫画书架/library.json`（Windows：`%APPDATA%/漫画书架`）
- 可用环境变量 `COMIC_USER_DATA` 指定其它目录（多书库 / 测试用）
- 原始漫画文件不会被修改或复制，APP 只做读取

## ⚠️ 已知限制

- 压缩包仅支持 **zip / cbz**（未加密）；RAR / 7z 需要额外解压工具
- WebDAV 需服务端支持 `PROPFIND`（绝大多数主流网盘支持）
- 图片尺寸探测只读文件头，因此能提前占位、滚动不跳动；个别特殊格式可能按默认比例估算，加载后会自动校正
- **带 DRM 的 MOBI/AZW3 仍无法读取**（加密是内容自带的，程序无法绕过）；检测到后会明确提示「带 DRM 保护，无法读取」
- EPUB 章节里的 **内联 CSS 背景图** 若与章节不在同一目录，可能显示不出来（章节正文插图、SVG 封面都正常）
